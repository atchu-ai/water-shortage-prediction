# 💧 AI-Powered Water Shortage Prediction System

An AI-powered system designed to predict water shortage risk and support smarter water distribution at the ward level.

## 🚀 Project Overview

Water shortage is a major challenge in many regions due to changing consumption patterns and limited water resources.

This project uses data-driven prediction to identify the water shortage risk for a selected ward and provides recommendations for better water distribution and resource management.

## ✨ Key Features

- 📍 Ward-wise water shortage prediction
- 📊 Water demand and consumption analysis
- ⚠️ Risk classification: Low, Moderate, High and Critical
- 🚨 Warning messages for high-risk shortage conditions
- 💧 Smart water distribution recommendations
- 🖥️ Interactive Streamlit web application
- 📈 Data-driven decision support

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Machine Learning
- Streamlit
- CSV Dataset
